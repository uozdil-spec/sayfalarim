# Gerçekçi resimli kartlar (isteğe bağlı)

Bu klasöre aşağıdaki adlarla PNG dosyaları koyarsan oyun J, Q, K kartlarında otomatik olarak onları kullanır.
Dosya yoksa yerleşik SVG çizimleri kullanılır.

Dosya adı: `RÜTBE_TAKIM.png` → `J_S.png`, `Q_H.png`, `K_D.png`, `K_C.png` ...
Rütbe: J, Q, K. Takım: S maça, H kupa, D karo, C sinek. Toplam 12 dosya.
İstemler için `kart-istemleri.md` dosyasına bak. Önerilen boyut: 600x800 piksel (3:4), şeffaf ya da krem zemin.
